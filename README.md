# ReboCaiz — Simulador simples

## Publicação no GitHub Pages
1. Abra o repositório `ReboCaiz` no GitHub.
2. Apague os ficheiros antigos do repositório (uma vez que ainda não existem dados de clientes que queira preservar).
3. Carregue **o conteúdo desta pasta**, não a pasta ZIP: `index.html`, `hero.jpg`, `manifest.webmanifest`, `sw.js`, `icon.svg`, `icon-192.png` e `icon-512.png`.
4. Faça commit das alterações.
5. Em Settings → Pages, confirme que a publicação usa a branch `main` e a pasta `/ (root)`.
6. Abra o endereço do GitHub Pages e, se a versão antiga continuar instalada, remova a aplicação antiga do ecrã inicial e volte a instalá-la depois de abrir o site atualizado.

## Utilização
- A página inicial apresenta a imagem e o botão para abrir o simulador.
- O tarifário começa vazio: taxa de saída, preço por km, mínimo, suplementos e IVA não são preenchidos automaticamente.
- Configure apenas os campos que pretende usar em **Definições** e guarde.
- Introduza os quilómetros totais do serviço manualmente. Esta versão não calcula rotas automaticamente.
- O IVA fica por definir se deixar o campo vazio.
- Histórico e definições são guardados localmente neste dispositivo/navegador. Não são sincronizados entre dispositivos.

## Nota
Testes automáticos de sintaxe e integridade do pacote não substituem testes em navegador real, teste de partilha WhatsApp e instalação em Android.
